# Predictive Modeling — OPIM 5604 | University of Connecticut

Python-based predictive analytics coursework covering the full SEMMA framework,
from data preprocessing to ensemble models and neural networks.

## Course Overview

**Course:** OPIM 5604 — Predictive Modeling  
**Program:** MS Business Analytics, University of Connecticut  
**Tools:** Python · Google Colab · scikit-learn · pandas · matplotlib

## Topics Covered

- Data preprocessing, exploration, and feature engineering
- Cluster Analysis
- Linear & Logistic Regression
- Classification and Regression Trees (CART)
- Bootstrap Forest & Gradient Boosted Trees
- K-Nearest Neighbors (KNN)
- Discriminant Analysis & Naive Bayes
- Neural Networks (MLP) & Ensemble Models

### 🔥 [Wildfire Risk Prediction](./wildfire-prevention)
